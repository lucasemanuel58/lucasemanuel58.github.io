## Estrutura

```
index.html   # conteúdo e semântica (um único arquivo, sem framework)
styles.css   # tema escuro, responsivo, sem dependências externas além da fonte
```

## Rodar localmente

É só abrir `index.html` no navegador. Se quiser servir via HTTP:

```bash
python -m http.server 8000
# http://localhost:8000
```
